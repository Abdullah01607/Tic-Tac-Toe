# Tic-Tac-Toe

A simple Tic-Tac-Toe game implementation in Python, complete with both a command-line interface and a modern graphical user interface (GUI). 

## Features
- **Terminal Version (`Tic-Tac-Toe.py`)**: Play the game directly from your console.
- **GUI Version (`Tic-Tac-Toe-GUI.py`)**: A visually appealing, windowed version of the game built using the standard Python `tkinter` library. It features a responsive layout, a 3x3 grid, color-coded player turns, win/draw detection, and a handy restart button.

## Requirements
- Python 3.x
- No external dependencies required! The GUI uses the built-in `tkinter` library.

## How to Play

### GUI Version
To play the graphical version of the game, simply run the GUI script:
```bash
python Tic-Tac-Toe-GUI.py
```
- Click on any empty square to make your move (Player X starts).
- The game will automatically detect and announce wins or draws.
- Click the "Restart Game" button to quickly clear the board and play again.

### Terminal Version
To play the command-line version of the game, run:
```bash
python Tic-Tac-Toe.py
```
- Follow the on-screen prompts to enter your moves using numbers (1-9).
